Git Pull (get latest changes from cloud and integrate locally):

Git push (commit your changes to the cloud):

git add  .  (adds anything that changed or was added)
git commit . -m "What changes were made"
git status
git log origin/main..HEAD --oneline  (to see what all is about to be pushed)
git push origin main

NOTE: 

main — your local branch
origin/main — the remote (cloud) copy, on GitHub
